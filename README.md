# Công cụ hỗ trợ dịch Plants vs Zombies: Fusion
## Cài đặt
Tải `PVZF-Translation` tại [đây](https://github.com/Teyliu/PVZF-Translation)

## Sử dụng
Vào thư mục gốc `pvzf-translator` chạy lệnh:
```sh
python trans.py đường/dẫn/PVZF-Translation/PvZ_Fusion_Translator/Localization
```

Dựa vào thông tin và dữ liệu trong thư mục được tạo mới `c`, sửa tệp tương ứng ngôn ngữ đích (VD: Việt Nam) trong đường dẫn `PVZF-Translation/PvZ_Fusion_Translator/Localization/Vietnamese`
